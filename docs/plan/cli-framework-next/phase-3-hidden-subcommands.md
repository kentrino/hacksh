# フェーズ3: 非表示のサブコマンド

[拡張計画](README.md)のフェーズ3。依存は[フェーズ1](phase-1-public-api.md)。ヘルプの統合検証は[フェーズ2](phase-2-args-and-help.md)の後に行う。

- [ ] `hidden` を追加する。親の一覧から隠すが、名前による実行とそのコマンド自身のヘルプは利用可能にする。

内部用や非推奨のコマンドを、ヘルプを読む利用者や AI エージェントに提示しないために使う。固定・可変長 positional とサブコマンドの併用禁止を維持する。

別名とデフォルトのサブコマンドは [deferred.md](deferred.md) に移した。

受け入れ条件: 非表示の子が親の一覧に出ないこと、名前による実行、そのコマンド自身の `--help`、未知名のエラー時に表示する usage にも非表示の子が出ないことを検証する。
