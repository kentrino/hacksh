# Problem

コマンドの引数、型、必須かどうか、選択肢、サブコマンドの構成を外部に示す手段は、人間向けのヘルプ文（`--help`・`renderUsage`）だけである。AI エージェントやツール定義（MCP など）へ変換する利用者は、ヘルプ文を解析するか、定義を別に書き直す必要があり、スキーマとの食い違いが起こりうる。

解決後は、コマンド定義と同じスキーマから、呼び出し方を機械可読な形式で取得できる。

# Open Decisions

- 取得の経路（ライブラリ関数、CLI のオプション、またはその両方）。
- 出力に含める範囲（非表示のサブコマンド、位置引数と名前付きオプションの区別、別名など）。
