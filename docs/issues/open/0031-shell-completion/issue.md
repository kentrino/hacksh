# Problem

コマンド名・フラグ・enum の選択肢は定義されているが、シェルの入力補完に使う手段がない。作者が補完を別に記述すると定義とのずれが生じる。

定義と同じ情報から静的な補完を生成できるようにする。

# Rules

- 0008の機械可読な定義を共通の情報源として使い、スキーマ解析を複製しない。
- 補完取得でrunや副作用のあるsetupを実行しない。
- 初期範囲はサブコマンド・フラグ・enum。外部コマンドを使う動的候補は含めない。
- インストール手順を示すが、ユーザーのシェル設定を自動変更しない。

# Acceptance Criteria

- 採用したシェルでネストしたサブコマンド、値を取るフラグ、enumの補完を検証する。
- 空白やシェルの特殊文字を含む候補が適切に扱われる。
- hidden・alias・-- の後の候補の扱いを明示する。
- 定義変更を補完へ反映でき、補完取得でrunが呼ばれない。

# Open Decisions

- 最初に対応するシェル（zsh/bash/fish）と生成・配布方法。
- lazyな定義0004や配列オプション0007を導入した際の情報取得範囲。
