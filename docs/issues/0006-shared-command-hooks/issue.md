# Problem

ログ、計測、認証などの前後処理を複数のコマンドで共有するには、各コマンドの `run` を利用者が手で包む必要がある。包み忘れたコマンドでは処理が行われず、それを検出する手段もない。

解決後は、共通の前後処理を一度定義すれば、対象のコマンドすべてに適用される。

# Open Decisions

- 0005 の前後処理の仕組みに載せるかどうか。0005 の判断に依存する。
- 利用者のエコシステムができる前に設計するかどうか。
- コマンド固有の前後処理との順序と、親からの継承。
