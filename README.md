# zitty

## Setup

```sh
vp install
```

## Scripts

| Command        | Description                      |
| -------------- | -------------------------------- |
| `vp check`     | Format, lint, and type check     |
| `vp test`      | Run tests                        |
| `vp pack`      | Build `src/index.ts` into `dist` |
| `vp run ready` | Run check, test, and build       |
